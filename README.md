# 🎆 Fireworks

A tiny interactive fireworks show in a single HTML file — no libraries, no build step.

- Click or tap anywhere to launch a rocket
- Random fireworks go off every 1.5 seconds
- Twinkling starry sky, gravity, and fading trails
- Works on desktop and phone

## Run it
Open `index.html` in any browser.

**Live demo:** https://ex-vigilante.github.io/fireworks/
